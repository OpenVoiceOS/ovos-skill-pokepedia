# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-04-13

### Added
- Initial release
- GetPokemonInfo intent - "Tell me about [Pokemon]"
- GetPokemonMoves intent - "What moves does [Pokemon] have?"
- GetPokemonType intent - "What type is [Pokemon]?"
- BattleComparison intent - "Who wins between [Pokemon A] and [Pokemon B]?"
- PokeAPI integration via pokepy library
- Child-friendly TTS output with type advantage explanations
- In-memory caching for API responses
